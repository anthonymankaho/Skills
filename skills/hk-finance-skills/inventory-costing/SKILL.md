# Inventory Costing (HKAS 2)

Calculate inventory values under Hong Kong Accounting Standard 2.

## Methods

| Method | HKAS Basis | Best For |
|--------|-----------|----------|
| FIFO | HKAS 2.25 | Perishable goods, price-inflation environments |
| Weighted Average | HKAS 2.25 | Commodities, homogeneous items |
| Standard Costing | HKAS 2.25 | Manufacturing with stable BOMs |
| Retail Method | HKAS 2.25 | Retail with consistent markups |

## NRV Write-down (HKAS 2.2)
Net Realizable Value = Estimated selling price − Estimated costs to complete − Costs to sell
Write down to NRV whenever carrying amount exceeds NRV. Reverse previously written-down amounts if conditions change.

## Absorption Costing (HKAS 2.11)
Include: purchase costs, conversion costs (direct labor + fixed/variable overhead), site management, normal capacity.
Exclude: abnormal waste, storage (unless necessary), admin overhead, selling costs.

## Output
Inventory valuation report showing method applied, NRV test results, and any write-downs needed.
