# Lease Accounting (HKFRS 16)

## Core Principle
Lessee recognizes **Right-of-Use Asset** and **Lease Liability** for ALL leases (except short-term ≤12 months and low-value assets).

## Mechanics

1. **Measure lease liability** = PV of unpaid lease payments using incremental borrowing rate
2. **Measure ROU asset** = lease liability + initial direct costs + prepaid rent − lease incentives
3. **Subsequent**: depreciate ROU asset (HKAS 16) + accrete lease liability (interest)
4. **Modifications**: remeasure liability at modification date, adjust ROU accordingly

## Exemptions
- Short-term leases (≤12 months)
- Low-value assets (new value ~HK$50,000 or below)

## Output
Lease register, ROU amortization schedule, lease liability roll-forward, and disclosure notes per HKFRS 16.
