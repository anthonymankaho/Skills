# Revenue Recognition (HKFRS 15)

Five-step model for revenue recognition under Hong Kong FRS 15.

## Five Steps

1. **Identify contract(s)** with customer (approval, identifiable rights, payment terms, commercial substance, probable collection)
2. **Identify performance obligations** (distinct goods/services)
3. **Determine transaction price** (fixed + variable consideration, constraining estimates)
4. **Allocate transaction price** to POs based on standalone selling prices
5. **Recognize revenue** when (or as) each PO is satisfied (point-in-time vs over time)

## Hong Kong-Specific Considerations
- **Construction contracts**: often satisfy PO over time (output/input method, HKFRS 15.35)
- **Software/SaaS**: multiple POs (license + implementation + support) require allocation
- **Trade discounts**: deducted from transaction price (HKFRS 15.72)
- **Warranties**: service-type warranties create separate PO (HKFRS 15.22)

## Output
Revenue recognition policy document, contract-by-contract PO analysis, and timing/recognition schedule.
