## How to use this vault

1. Start from one of the two main sections above.
2. Open the repository page for its GitHub URL, local checkout, purpose, entry points and handling notes.
3. Read the repository README and current SOP before processing or changing code.
4. Use linked project notes for background and prior decisions; verify dated operational details against the current repository and source files.

## Scope and boundaries

This vault is an index and working knowledge layer. GitHub repositories hold versioned code and shared documentation. Source statements, production workbooks, credentials and generated reports may be local-only or ignored by Git. Confirm the storage boundary in each repository before sharing or syncing files.
