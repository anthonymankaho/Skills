# Skill: Dataviz

Load before writing any chart, graph, plot, dashboard, or data visualization — in any medium (HTML/React artifact, inline SVG, matplotlib/plotly/d3/Recharts code, or a chart shared into Slack). Teaches a design-system-agnostic method: a form heuristic, a color formula with a runnable validator, mark specs, and interaction rules, aiming for visuals that read as one consistent system in light and dark themes. A validated default brand-neutral palette lives in `references/palette.md` for swapping in a real brand's colors.
