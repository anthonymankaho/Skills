# Skill: Design (Canvas)

Creates a design canvas — a multi-artboard visual design published as an Artifact running Claude Design's canvas editor. Claude drafts `.dc.html` artboards on one pan/zoom canvas; where saving is enabled, the user refines every element visually (click-to-select, properties panel, inline text editing, undo/redo) and Save publishes a new version. Good for UI mockups, screen flows, landing pages, marketing/social graphics, and print pieces (posters, flyers, brochures, memos). Only for creating/re-seeding a canvas — an existing one is edited in its published Artifact.

## Full detail
Built into Claude Code — no separate SKILL.md on disk; invoked via the `design` skill name.
