# Skill: Run

Launches and drives the current project's app to see a change actually working — asked to run/start/screenshot the app, or to confirm a change works in the real app (not just tests). Checks for a project-specific launch skill first; otherwise falls back to built-in patterns by project type (CLI, server, TUI, Electron, browser-driven, library).

## Full detail
Built into Claude Code — no separate SKILL.md on disk; invoked via the `run` skill name.
