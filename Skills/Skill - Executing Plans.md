# Skill: Executing Plans (Superpowers)

Use when a written implementation plan needs to be run in a separate session with human review checkpoints (no subagents available — otherwise prefer [[Skill - Subagent-Driven Development|subagent-driven-development]]). Load the plan, review it critically for gaps, execute tasks one by one following each bite-sized step exactly, run the specified verifications, and stop immediately on any blocker rather than guessing. Finishes by handing off to [[Skill - Finishing a Development Branch|finishing-a-development-branch]].
