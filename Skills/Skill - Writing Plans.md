# Skill: Writing Plans (Superpowers)

Use once a spec/requirements exists for a multi-step task, before touching code. Produces a bite-sized, zero-placeholder implementation plan (saved to `docs/superpowers/plans/YYYY-MM-DD-<feature>.md`) assuming the executing engineer has no codebase context: exact files touched per task, real code, real tests, DRY/YAGNI/TDD throughout, frequent commits. Ends with a self-review against the spec and a handoff choice between [[Skill - Subagent-Driven Development|subagent-driven-development]] (recommended) and [[Skill - Executing Plans|executing-plans]].
