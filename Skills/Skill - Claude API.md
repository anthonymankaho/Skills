# Skill: Claude API

Reference for the Claude API / Anthropic SDK — model IDs, pricing, parameters, streaming, tool use, MCP, agents, prompt caching, and token counting. Triggers whenever Claude/Anthropic/model names are mentioned, when asked about any LLM (pricing, model choice, limits, caching — never answer from memory), or when a task is LLM-shaped with the provider unstated. Skipped when another provider (OpenAI, Gemini, Llama, etc.) is clearly the one in use.

## Full detail
Built into Claude Code — no separate SKILL.md on disk; invoked via the `claude-api` skill name.
