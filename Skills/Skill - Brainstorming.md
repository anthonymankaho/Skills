# Skill: Brainstorming (Superpowers)

Mandatory first step before any creative work — new features, components, functionality, or behavior changes. Classifies the request into **Spike** (feasibility question, no design doc), **Bounded** (small well-scoped change to existing code, short in-chat design), or **Architectural** (new subsystems/projects, full spec + [[Skill - Writing Plans|writing-plans]] handoff). Every path ends with an explicit approval gate before implementation starts — "simple" never means "no approval."
