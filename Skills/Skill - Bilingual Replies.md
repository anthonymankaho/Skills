# Skill: Bilingual Replies

Standing instruction: every substantive reply in this working relationship must be written in **both English and Traditional Chinese (繁體中文)** — never English-only or Chinese-only, regardless of which language the user writes in. Code, paths, commands, and identifiers stay untranslated; only surrounding prose needs both languages. Trivial one-line tool-narration doesn't need duplication, but the actual answer/explanation/summary does.
