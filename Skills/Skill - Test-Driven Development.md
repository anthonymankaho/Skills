# Skill: Test-Driven Development (Superpowers)

Use before writing any implementation code, for every feature or bugfix. Iron law: **no production code without a failing test first**. Red-Green-Refactor cycle: write one minimal failing test, verify it fails for the right reason, write the simplest code to pass, verify it passes with no other breakage, then refactor while staying green. Code written before its test must be deleted and redone — never kept "as reference."
