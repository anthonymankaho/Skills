# Skill: Verification Before Completion (Superpowers)

Use before claiming work is complete, fixed, or passing — before committing or creating PRs. Iron law: **no completion claims without fresh verification evidence run in this message**. Identify the command that proves the claim, run it in full, read the actual output, and only then state the claim — with the evidence. Bans hedge words ("should work", "probably passes") and premature satisfaction ("Great!", "Done!") before that evidence exists.
