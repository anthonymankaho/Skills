# Skill: Simplify

Reviews changed code for reuse, simplification, efficiency, and "altitude" cleanups, then applies the fixes directly. Quality-only — it does not hunt for bugs; use [[Skill - Code Review|code-review]] for that.

## Full detail
Built into Claude Code — no separate SKILL.md on disk; invoked via the `simplify` skill name.
