# Skill: Loop

Runs a prompt or slash command on a recurring interval (e.g. `/loop 5m /foo`) — omit the interval to let the model self-pace. Use for recurring tasks or polling for status ("check the deploy every 5 minutes", "keep running /babysit-prs"), not for one-off tasks.

## Full detail
Built into Claude Code — no separate SKILL.md on disk; invoked via the `loop` skill name.
