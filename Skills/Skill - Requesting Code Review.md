# Skill: Requesting Code Review (Superpowers)

Use when completing a task, finishing a major feature, or before merging — dispatch a code-reviewer subagent with precisely crafted context (git SHAs, description, requirements) rather than the coordinator's own session history, so review context stays clean and reusable. Fix Critical issues immediately, Important issues before proceeding, note Minor issues for later, and push back with reasoning if the reviewer is wrong. Distinct from [[Skill - Receiving Code Review|receiving-code-review]], which governs how to act on the feedback once it arrives.
