# Skill: Update Config

Configures the Claude Code harness via `settings.json`/`settings.local.json`: hooks for automated behaviors ("from now on when X", "whenever X"), permissions ("allow X", "add permission"), environment variables, and hook troubleshooting. For simple settings like theme or model, `/config` is suggested instead.

## Full detail
Built into Claude Code — no separate SKILL.md on disk; invoked via the `update-config` skill name.
