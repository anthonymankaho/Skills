# Skill: Receiving Code Review (Superpowers)

Use when receiving code review feedback, before implementing any of it — especially when it seems unclear or technically questionable. Requires reading the full feedback, restating the requirement, verifying against the actual codebase, and only then implementing one item at a time with tests. Forbids performative agreement ("You're absolutely right!", "Great point!") and blind implementation; pushes back with technical reasoning when a suggestion is wrong, breaks something, or violates YAGNI, and asks for clarification rather than guessing on unclear items.
