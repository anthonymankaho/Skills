# Skill: Dispatching Parallel Agents (Superpowers)

Use when facing 2+ independent problems (e.g. unrelated test failures across different files/subsystems) that share no state and don't depend on each other. Review and integrate results afterward, then run the full suite to confirm no conflicts.
